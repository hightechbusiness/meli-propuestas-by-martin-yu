# Meli Propuestas

<sub>by Martin Yu · Propuestas que conectan</sub>

![Propuestas que conectan · Gestión Comercial · Martin Yu](assets/portada.svg)

Una herramienta para convertir condiciones comerciales en propuestas claras, visuales y fáciles de compartir.

Pensada para acompañar el trabajo de los asesores: elegir qué mostrar, adaptar el mensaje y presentar una propuesta que cada comercio pueda entender.

[Conocer la herramienta y solicitar acceso](https://propuestas-que-conectan.pages.dev/solicitar-acceso/)

[**Probá Meli Propuestas →**](https://hightechbusiness.github.io/meli-propuestas-by-martin-yu/)

Un diseño, edición simple y descarga PDF. Usa condiciones ilustrativas; no contiene tablas comerciales internas. La versión completa se solicita por separado.

## Cómo fue creciendo

| Etapa | Mejora incorporada |
| --- | --- |
| Una propuesta propia | Perfil de cada asesor, mensaje y presentación personalizables. |
| Una comunicación más clara | Diseño adaptable a celular y web, español o chino y exportación PNG/PDF. |
| Trabajo en equipo | Acceso verificado, opciones avanzadas y actividad privada para el responsable. |
| Una puerta abierta | Esta demo y un espacio público para compartir ideas y seguir mejorando. |

Es un recorrido de las funciones incorporadas. La demo muestra el estilo actual; no reproduce versiones antiguas ni datos internos.

## Una propuesta, a tu manera

| Para el asesor | Para cada comercio |
| --- | --- |
| Editor con pasos breves y campos personalizables | Información presentada con una jerarquía visual clara |
| Opciones para elegir el contenido y el diseño | Una propuesta adaptada a la conversación comercial |
| Exportación en PNG y PDF | Archivos listos para compartir |
| Español y chino simplificado | Un solo idioma por propuesta |
| Uso en celular y computadora | Una experiencia práctica en distintos formatos |

El generador operativo requiere un correo verificado y acceso autorizado. Este espacio público presenta el proyecto y reúne ideas para mejorarlo; no contiene tablas comerciales internas, propuestas de clientes ni el código privado del generador.

## Ayudá a que la próxima versión sea mejor

**Dejá una estrella.** Si te resultó útil, podés usar el botón **Star** de este repositorio. Necesitás una cuenta de GitHub; es una forma de guardar el proyecto y mostrar interés, no un requisito para usar la herramienta.

**Compartí una idea.** Abrí un *issue* con una mejora concreta: qué querés resolver, en qué momento aparece la dificultad y cómo te gustaría que funcionara.

**Contanos qué falló.** Describí los pasos para reproducir el problema y qué esperabas que pasara. Podés usar las plantillas de este repositorio o escribir por correo.

Al compartir ejemplos o capturas, usá datos ficticios y ocultá contactos de clientes y condiciones comerciales internas. Para un caso que necesite detalles privados, elegí el correo.
